# krutoiAIraspoznovatelBot 🔩🤖

Бот на основе ИИ-модели для автоматического распознавания типа металла по изображению.

Модель определяет один из следующих материалов:
- 🟫 **Карбон**
- 🟠 **Медь**
- 🟡 **Латунь**
- ⚙️ **Железо**

## 📌 Описание

Проект использует модель компьютерного зрения (нейронную сеть), обученную классифицировать металлы по фотографии. Пользователь отправляет изображение объекта, а бот определяет, из какого материала он изготовлен, и возвращает результат с указанием уверенности модели (confidence score).

## 🚀 Возможности

- Распознавание металла по фото в реальном времени
- Поддержка 4 классов материалов: карбон, медь, латунь, железо
- Простое взаимодействие через Telegram-бота (или другой интерфейс — уточните при необходимости)
- Быстрая обработка запросов

## 🛠️ Технологии

- Python
- Библиотека для работы с нейросетями (PyTorch / TensorFlow — уточните используемую)
- Telegram Bot API (или иной интерфейс)
- OpenCV / Pillow для предобработки изображений

## 📦 Установка

```bash
git clone https://github.com/your-username/krutoiAIraspoznovatelBot.git
cd krutoiAIraspoznovatelBot
pip install -r requirements.txt
```

## ⚙️ Настройка

1. Создайте файл `.env` и укажите необходимые переменные окружения, например:
```
BOT_TOKEN=your_telegram_bot_token
MODEL_PATH=path/to/model.pth
```
2. Убедитесь, что веса модели загружены в указанную директорию.

## ▶️ Запуск

```bash
python main.py
```

## 🖼️ Пример использования

1. Отправьте боту фотографию металлического изделия.
2. Получите ответ с предсказанным классом материала и уровнем уверенности:

```
Результат: Латунь
Уверенность: 94.2%
```
